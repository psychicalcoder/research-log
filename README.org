#+TITLE: Research log — site source

One-column research blog written in Org mode and exported with =ox-publish=.

* Layout

#+begin_example
publish.el          all export configuration (the design lives here as much as in the CSS)
Makefile            make / make rebuild / make serve
org/
  _intro.org        the paragraph at the top of the home page  (edit this)
  index.org         GENERATED on every build: intro + post list (do not edit)
  about.org
  posts/            one .org file per entry; the home page lists them newest-first
  css/style.css
  fonts/            Manrope, IBM Plex Mono; self-hosted (latin subsets)
  img/
html/               output; deploy this directory
#+end_example

* Writing a post

Create =org/posts/YYYY-MM-DD-slug.org=:

#+begin_example
,#+TITLE: A baseline I can trust
,#+DATE: <2026-09-02 Wed>
,#+DESCRIPTION: One sentence shown under the title on the home page. Optional.

Body...
#+end_example

- =#+DATE= is used for sorting and for the dateline; without it the file's mtime is used.
- Long post? Add =#+OPTIONS: toc:2=.
- Figures: =#+CAPTION:= then =[[file:../img/name.svg]]=. They are capped at column width and never upscaled, so export at ≥ 1300 px wide (or use SVG).
- Tables: =#+CAPTION:= above the table; =|---|= lines become hairlines.
- Math: =$...$= inline, =\begin{equation}= for numbered display. MathJax 3 from jsDelivr is the only external request the site makes.
- Link between posts with =[[file:other-post.org]]=; Org rewrites the extension.

* Building

#+begin_example
make            # incremental
make rebuild    # everything (after changing publish.el or the CSS)
make serve      # http://localhost:8000
#+end_example

Inside Emacs: =M-x load-file RET publish.el RET=, then =M-x org-publish-project RET site RET=.

Install the =htmlize= package if you want syntax highlighting in code blocks; the CSS already
styles its classes (keywords in ultramarine, strings in green, comments in grey). Without it, code is plain text.

* Design rules (so the site stays this way)

- White watercolour paper: a faint cold-pressed grain (an SVG light filter) on white. The only painted mark is a dry brushstroke for =hr= and footnotes.
- On desktop the page takes two thirds of the window. A left rail (22%) holds dates and section
  numbers; running text is capped at 44rem (=--measure=). Phones get one column.
- Two faces: Manrope for everything, IBM Plex Mono for code only.
- One accent colour, ultramarine (=--accent=): section numbers, link hover, code keywords.
- Hairlines (=--rule=) separate. Quotes get a thin dark left rule. Light only, no dark mode.
